# MRI rmResident prototype — Amenify Partners

Live demo: https://amenify-mri-prototype.vercel.app/

13-screen clickable prototype showing how MRI rmResident residents earn rmCash and rmPoints by paying rent with a Visa card. Includes the linked-card spend flow (Why → Link → All Set → Order with Maddie) and a Services Wallet (Anna C. cleaning Pro + popular services grid).

**Persona:** Sarah Thompson · Villa Verano · $2,105/mo rent · Cincinnati, OH
**Reward economics:** 1.0% rmCash on Visa rent payments ($21.05 on $2,105), 1 rmPoint per $0.25 of rent paid (8,420 points), rm Plus upsell at $9.99/mo for ACH payers.
